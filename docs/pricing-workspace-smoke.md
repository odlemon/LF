# Pricing workspace smoke (Module 02)

1. Open a pricing request with **Confirm Scope** done (status `SCOPE_CONFIRMED`).
2. Click **Continue to pricing** → empty workspace hero with **Generate scenarios**.
3. Click **Generate** → 2–3 DRAFT scenarios (FIXED_FEE / HOURLY_WITH_CAP / HYBRID).
4. Select a card → adjust hours % / discount → **Recalculate** (rejects margin below firm floor).
5. **Set as preferred** → **Submit to Partner** → status `PENDING_PARTNER`.
